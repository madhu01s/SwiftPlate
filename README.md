# SwiftPlate 🍽️

SwiftPlate is a modern full-stack food delivery web application built using Django.

## 🚀 Features

* User Authentication
* Food Browsing
* Cart Management
* Stripe Payment Integration
* Cash on Delivery
* Order Tracking
* Responsive UI Design

## 🛠️ Tech Stack

* Python
* Django
* HTML
* CSS
* JavaScript
* SQLite
* Stripe API

## 💡 Project Idea

SwiftPlate was built to reduce the high commission charges imposed by food delivery platforms like Swiggy and Zomato.

### Business Model

* Restaurants pay only 10–15% commission
* Customers pay 0% platform fee
* Affordable and transparent delivery ecosystem


## ▶️ Installation

```bash
git clone https://github.com/madhu01s/SwiftPlate.git
cd SwiftPlate
pip install -r requirements.txt
python manage.py runserver
```
